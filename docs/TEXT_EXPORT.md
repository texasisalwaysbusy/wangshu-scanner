# 带页码的 UTF-8 文字副本（开发预览）

基线为草稿 PR #2 的 `52832f916e2b78a71f9f74f1994e800efec22731`。本代只导出文字快照，不改 OCR 引擎、页面图像或可搜索 PDF 文字层，不推断公式的正确写法。

## 使用方式

文稿中的“另存文字副本”可选整本已保存文字。编辑页还可选择当前页已保存文字或当前草稿副本；草稿来源明确标为未保存，导出不会提交页面。单页仍使用它在整本文稿中的页码。空白文字页保留页码与状态，正文中的中文、emoji、换行和公式原样写入 UTF-8。

每页分开标注：是否已保存到文稿、自动识别／人工编辑／旧版来源未记录、OCR 图像参数是否匹配、四角是否确认。人工编辑不代表已逐字核验，四角确认也不代表文字正确。旧图像参数文字只供参考；编辑不会把旧 OCR 基线变成最新。旧数据没有来源字段时保持“未记录”，不会被追认为人工校对。

生成后显示来源、文件名和实际字节数，用户确认后主动选择新文件。已保存来源不包含未保存的编辑。快照与文稿不会自动同步；重新使用先前快照或恢复缓存时，界面明确提示未重新核对当前文稿。

## 目标、失败与恢复

通过系统 `ACTION_CREATE_DOCUMENT` 选择位置。`EXTRA_LOCAL_ONLY` 仅为提示；**由用户选择保存位置，存储或同步取决于所选文档提供者**。Android 的 [Storage Access Framework 说明](https://developer.android.com/guide/topics/providers/document-provider)允许本地及云提供者，URI 不能证明物理离线。

TXT 路径使用 `rw` 描述符，不请求截断；只接受系统文档 URI，并在打开的描述符上确认普通文件且大小为零，再开始写入。非空、管道、大小未知或提供者不支持该协议时明确拒绝，用户需另建文件。没有依赖显示名称或可空的文档大小元数据。此保护依赖提供者遵守 Android 描述符契约，不能保证任意提供者或外部并发写入行为。

来源在私有缓存生成，实际编码输出最多 32 MiB（含页头）；超限或无效 Unicode 报错，保留原始文字，不截断。完整候选用独立新路径写入并核对 SHA-256；失败的部分缓存也保留。缓存可能被系统清理，不是持久备份。普通 ZIP 不包含这类缓存或保存回执。

文稿、页序、页面身份、编辑会话或草稿变化使迟到回调失效；重新生成后再选择位置。重复回调不能再次打开目标，失败状态在释放写入所有权前记录。取消或写入失败不会修改原文稿或草稿；旧目标可能是部分文件，界面提示失败并保留它。重试必须再次确认旧快照并另选新文件，不自动重写旧 URI。

进程重建后不恢复旧目标写入授权。文库的未完成保存记录允许核对文字快照后另选位置；缓存缺失时可明确“结束旧文字请求”，只结束匹配的 TXT 回执，不删除源或目标，不影响新请求。没有缓存就不能恢复那份文字副本，应从保留的文稿或草稿重新生成。未保存草稿能否跨进程恢复仍受既有独立恢复和生命周期快照边界约束。

保存完成表示来源校验、写入／刷新／关闭和回执完成，不包含外部提供者的读回哈希、断电持久性或云端同步确认。

## 本代验证边界

`tools/test_host.py` 纳入 `text_export` 和 `text_export_ui` 两组集中回归。前者执行生产格式器、Models、来源变更回滚、SaveJobStore 和目标写入协议，使用合成真实文件；回执持久化和 Android／JSON 是主机替身。后者提取生产 MainActivity 的来源选择、确认、保存结果和恢复回调；UI、Store、调度及描述符接口为替身，Android 描述符接线仅做结构检查。

覆盖空页、多页页码、中文／emoji／换行／公式、人工／自动／未知／过期来源、未保存草稿、调序／文稿／会话变化、取消、非空／未知目标、写失败与新目标重试、重复回调、真实线程写入互斥、缓存丢失出口及 4.2 MB 草稿。测试不读取私人素材，不联网、不安装软件。

本代集中运行 28 个检查条目全部通过，记录的平台跳过为 0，运行前后生产源码散列一致。新增核心组 18 场景／64 断言，生产 UI 回调组 15 场景／28 断言；独立审查者分别重跑这两组并验证写入期间禁止结束请求、非 TXT 请求不受影响。独立审查确认的失败状态竞争与缓存丢失阻塞均已修复；这些数量不代表真实 Android 场景通过。另对 40 个生产 Java 文件进行语法解析，无语法错误。
