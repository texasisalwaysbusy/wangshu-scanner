## 2. 每层开始前的记录与数据保护

记录候选源码完整 SHA、构建来源／标识、实际 APK 的 SHA-256（如已有）、包名、versionCode／versionName、签名证书指纹、系统 API／ABI、模拟器或真机、所选文档提供者以及时间。不要记录或公开设备序列号、账户、私人路径、密钥或真实扫描素材。签名证书指纹用于比对，不是私钥。

源码当前仍声明 `org.wangshu.scan`、versionCode `6`、versionName `0.2.4-preview-recovery-verify`；这些值未随三代源码自动改变，**不能单凭“code 6”确认装入了本代**。设备层必须关联到具体构建及源码 SHA；没有这一关联就停止归因。后续分发前另行确定版本号和签名政策，本清单不修改它们。

设备层仅使用独立的合成文稿。若已有合成数据需要保留，先记录文稿数、页序、页面文字及恢复记录状态，并分别保留所需副本。普通 ZIP 不包含独立恢复记录、生命周期快照、文字缓存或保存回执；参数副本也不含原图，不是完整备份。签名／包名不符、候选不明或升级要求清除数据时停止，不卸载、不清除数据、不降级、不强行覆盖。本文不要求进行升级或安装；若另有已授权的同签名保留数据升级，须先验证上述前置并在升级后核对旧合成数据。

所有用例共享失败保护：遇非预期失败，停止当前用例以外的保存／采用；保留应用数据、旧目标、原图、候选及恢复记录，记录用例编号和具体状态。预期故障保留证据后可按该用例明确的新目标／重试步骤继续。不用卸载、清缓存、删除文件、改权限／安全设置来“修好”结果，不公开运行日志或完整交接包。

## 3. 合成输入

准备一份三页合成文稿，图像上有易区分的页标记 A／B／C。A 含印刷中英文字、两行正文及公式 `a² + b² = c²`；B 为可确认的空白页；C 含另一组印刷文字。保留一份相同的合成原图副本供目视对照。文字纠错时手工输入固定标记 `人工-A-17`、`人工-C-29`，并加入 `中文😀`、空行及行末空格用于逐字导出核验。

图像 OCR 输出不要求等于这些手工标记，也不以公式／emoji 的识别成败判断工作流通过。重识别候选允许与原文字相同、不同或为空；验收重点是来源、确认、保存和保留行为。真实中文识别质量需另行准备标注语料与项目模型评估，本阶段不声称精度提升。

## 5. E／P 层最小功能集

模拟器先完成全部可执行项；真机至少重复 F1–F7、T1–T3、R1–R2、D1–D2。只有已有可核验候选时才执行，不要求本轮产生或安装新 APK。

恢复正向用例依赖顺序为 **F4 → F5 采用但不保存 → R1 载入旧稿但不保存 → F5 后半重新采用并保存新候选 → R2 冲突核对**，这段期间不要另行保存或调序该文稿。F3 和 R2 的生命周期部分使用另外的合成副本，避免改变正向载入所需基线。

| 编号 | 最小步骤 | 预期 |
| --- | --- | --- |
| F1 逐页纠错 | 导入 A／B／C，核对四角；打开 A 输入 `人工-A-17`；保存并下一页，核对空白 B，在 C 输入 `人工-C-29`，末页保存返回文稿；重开 A／C | 每页只保存自己的输入，末页不绕回；未保存与已保存状态准确，原图不变 |
| F2 快速切换与 IME | 在 A 连续输入中文及 emoji，快速请求切页／返回；保留草稿后重开；在 C 输入不同标记 | 导航按现有确认流程处理未保存输入；旧 IME／渲染回调不能把 A 的文字落到 C；相同页 ID 的新会话也不能接收旧回调。无法稳定制造迟到输入则保留“主机覆盖、真实 IME 未测” |
| F3 参数与旧文字 | 在独立合成副本中先生成、采用并保存一次单页候选，确认有有效 OCR 键且显示当前图像对应文字，而非“尚无识别基线”；再改变旋转／裁切或增强参数，查看状态并手工改字 | 旧识别基线保持过期，人工编辑不把旧文字伪装为最新识别或已校对无误；图像预览对应本页，原图保留。未建立真实 OCR 基线则此项未测，不能只用手输文字代替 |
| F4 单页候选保留 | 在 A 追加仅存在于草稿的标记 `旧稿-保留-41`，确认与已保存 A 不同且不保存；生成单页中英候选，比较两份完整文字；选择保留原修订，再生成并复制候选 | 两次均不自动替换或保存当前文字，不影响 B／C；候选是“自动识别、未校对”，复制不是保存；公式原样呈现，不臆造修正 |
| F5 明确采用与来源 | 再生成候选，确认“保留旧稿并采用候选”；重看状态，**暂不保存，立即先执行 R1**；R1 完成后重新生成并采用候选，再正常保存，供 R2 核对冲突 | 采用前已保留含 `旧稿-保留-41` 的完整未保存旧稿；只将候选放入草稿并标自动来源；保存前已保存页不变。正常保存后重开来源／文字一致，PDF 不被同步修改 |
| F6 取消、过期与重复 | 生成时取消；另一次生成后按 Home 返回或改变参数／输入，再查看旧候选；连续点击采用按钮 | 取消／失败保留原文字；过期候选只能查看／复制，不能套到当前页；重复采用最多一次，不重复覆盖。取消太快／太慢无法命中时标未测，不能把 UI 响应当原生 OCR 已及时停止 |
| F7 空结果与较大输入 | B 若真实返回空候选，核对清空警示，先保留再明确采用；在单独合成页粘贴较大中文文本，尝试保留／采用／保存 | 空结果不是 null 失败；清空需明确采用且旧稿先保留。超限不得截断或卡进不可编辑恢复页；完整原文仍可复制／编辑／返回。无法真实得到空候选则该分支仍未测；精确字节临界值以 H2 为证据 |
| T1 文字来源与页码 | 在 A 当前草稿追加与已保存版本不同的 `导出草稿-未存-53` 及 `中文😀`、空行／行末空格，不保存；分别导出整本已保存文字、当前页已保存文字、当前页草稿到三个新文件；按正常确认流程处理草稿后调序 C／A／B，重新生成整本 | 已保存来源排除 `导出草稿-未存-53`；草稿含完整未保存文本并标“未保存”；每页页码按各自生成时顺序，旧快照不自动变成新顺序；空页保留页号，中文／emoji／换行及行末空格不丢失 |
| T2 目标与取消 | 在系统选择器取消一次，再主动新建文件；若提供者能返回既有非空目标，验证拒绝；快速重复触发保存 | 取消不写目标、草稿不变；实际确认空的普通文档才能写入，非空／未知／不支持描述符协议应明确拒绝；重复回调不再次打开或覆盖。另存位置可能同步，由提供者决定 |
| T3 失败与新目标重试 | 仅用提供者支持的安全故障方式或测试提供者模拟写入失败；查看失败回执，重新确认旧快照并新建不同目标；另仅在缓存已自然失效或已有安全受控条件时检查“结束旧文字请求” | 明确提示失败，旧目标可能为半成品并保留；不自动重写旧 URI；新 token／新目标可重试。缓存缺失可明确结束匹配的旧 TXT 回执再重新生成，源／旧目标均不删除。无条件则相应分支未测，不填满真实存储、撤销系统权限、清缓存或手动删文件制造故障 |
| R1 旧稿正向载入 | 紧接 F5 采用后、保存本页前，按返回打开离开确认，再点“放弃本次修改”回到文稿，之后返回文库（不删除恢复记录）；打开“找回编辑恢复记录”，选择含未保存 `旧稿-保留-41` 的这份旧稿，核对原版本后载入；只核对，不保存旧稿，接着执行 F5 后半 | 完整旧人工修订以编辑预览出现，仍需明确保存才生效。必须选原版本、页面、原图均匹配且编辑内容不同于已保存页的合成记录；若全是已保存／冲突记录，本项仍未测，不以“列表看得到”替代载入通过 |
| R2 冲突与生命周期 | 保存 F5 的新稿后再选旧记录尝试载入；另在单独合成页保留未保存输入，按 Home 返回，重建 Activity 后核对 | 冲突旧稿拒绝覆盖新版本，仍可查看／导出；生命周期恢复不写错页。Home 往返不等于进程重建；没有受控 Activity／进程重建条件则分别标未测。单页候选本身不承诺跨进程保留 |
| D1 原图／既有资料 | 前后核对合成文稿数、页序、原图副本和恢复记录；若执行了另行授权的保留数据升级，重复核对旧合成文稿 | 没有意外删除或覆盖；普通 ZIP 的排除项保持明确，不能当完整恢复区备份；不因遇错而卸载或清数据 |
| D2 PDF 搜索边界 | 选择不同于图像的手工纠错标记；生成可搜索 PDF，在现有外部阅读器搜索／复制实际 OCR 文字；另存 TXT 比较人工标记 | PDF 保留导出时已保存页面的裁切／增强图像内容，不因编辑文字而改变图片；不承诺与原图字节／分辨率相同。文字层仍由重新 OCR 生成，人工标记不应因编辑字符串而自动进入 PDF；搜索失败需区分 OCR 输出、阅读器和文件问题。TXT 可包含人工标记，两者行为不同属当前设计，不声称公式或中文识别无误 |

F7 的保留失败、T3 的写入中断、R2 的真实进程重建及写盘中强制中断，需要可控的合成测试环境和独立记录。当前未提供设备故障注入开关；无法安全复现就保持未测，不改用户数据、不使用真实素材、不把主机注入 writer 等同于 Android AtomicFile 故障验收。

## 6. 结果记录与阶段出口
